Notes on the larger differences:

- 12.a apparent sidereal time and 22.a nutation: the package uses the
  four-term nutation series that Meeus gives for 0.5″ accuracy, not the full
  IAU 1980 table.
- 33.a Venus: Meeus evaluates VSOP87; the package uses JPL's approximate
  Keplerian elements (Standish), which trade a few arcseconds for a table of
  seven rows.
- 49.a new Moon: the time is found by root-finding on this package's own Sun
  and Moon positions instead of Meeus's dedicated phase series.
